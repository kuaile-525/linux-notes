# linux-notes

> 23 周 Linux / 运维安全学习笔记仓。目标：从零基础到能看懂日志、能写巡检脚本、能排查基础故障的准安全运维工程师。  
> 主线课程：Linux 入门到精通（韩顺平），配合实际敲命令 + 每周复盘。

## 这个仓库是什么

我是网络空间安全专业学生，求职方向为**安全运维 / 安全运营（SOC）**。这个仓库是我 2026.9 – 2027.2 的主线学习记录，按周组织，每周一个笔记文件，**所有命令都亲手敲过、截图留档**，笔记里专门标注了运维/安全视角的用法（比如哪条命令是排查日志用的、哪个操作容易造成事故）。

规划路线（与仓库目录一一对应）：

| 阶段         | 周次      | 内容                                              | 产出                               |
| ---------- | ------- | ----------------------------------------------- | -------------------------------- |
| 一：Linux 基础 | W1–W5   | 安装/目录结构/权限用户/Shell 脚本/高级篇                       | week01–05 笔记 + scripts/ 巡检脚本     |
| 二：计算机网络实操  | W6–W7   | 抓包、协议分析、组网实验                                    | 计网大笔记                            |
| 三：Web 安全   | W8–W13  | OWASP Top 10（XSS / SQLi / 文件上传 / 越权 / SSRF）靶场复现 | writeup × 6（另见 vuln-writeups 仓库） |
| 四：综合       | W14–W23 | 考试季 + 简历定稿 + soc-lab 搭建                         | 见 soc-lab 仓库                     |
